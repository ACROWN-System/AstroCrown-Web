# A. Verification Ecosystem Map

## A1. Security and software assurance

**Control / standard layer**
- NIST SP 800-218 SSDF v1.1
- NIST CSF 2.0
- OWASP ASVS 5.0.0
- CIS Critical Security Controls v8.1
- ISO/IEC 27001:2022
- ISO/IEC 27701:2025
- SOC 2 / AICPA Trust Services Criteria
- CSA STAR
- PCI DSS v4.0.1

**Testing / verification layer**
- static analysis
- dependency analysis
- secret scanning
- SAST/DAST
- penetration testing
- fuzzing
- invariant testing
- formal verification
- manual code review
- threat modeling
- red-team / adversarial review
- bug bounty / attackathon / audit contest

**External assurance providers / platforms**
- OpenZeppelin
- Trail of Bits
- Certora
- CertiK
- Halborn
- ChainSecurity
- Quantstamp
- Zellic
- Veridise
- Runtime Verification
- Immunefi
- Code4rena
- Sherlock
- Cantina
- HackerOne / Bugcrowd

## A3. Regulatory / legal / compliance pathway
- SEC (United States)
- ESMA / MiCA (EU)
- FCA (United Kingdom)

- jurisdiction-specific competent authorities discovered through a future jurisdiction map

## A8. Media / editorial visibility
- Reuters
- Bloomberg
- Forbes
- CoinDesk
- Cointelegraph
- specialist crypto/security press
- independent investigative journalists

Media coverage is a discovery/reputation mechanism, not independent security or financial certification.

## A9. Community / open-source validation
- GitHub
- Reddit
- Discord
- Telegram
- Snapshot
- Tally
- DAO governance forums
- issue trackers
- release histories
- public incident disclosures

Community signals vary by identity assurance, moderation, incentives, and susceptibility to manipulation.

## A10. Adversarial / threat-intelligence validation
- CISA and CISA Known Exploited Vulnerabilities
- CERT/CC and national CERT organizations
- Google Project Zero-style vulnerability research
- threat intelligence vendors
- incident-response organizations
- public exploit databases / CVE ecosystem
- coordinated vulnerability disclosure programs

## Coverage rule
Do not stop at famous entities. Continue ecosystem discovery until additional findings produce diminishing returns, while preserving long-tail candidates and unresolved gaps rather than collapsing them into a popularity-based list.
