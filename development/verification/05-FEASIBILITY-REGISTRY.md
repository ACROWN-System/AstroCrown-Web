# E. Feasibility Registry

## Feasible now
- Internal mapping against NIST SSDF, NIST CSF, OWASP ASVS, WCAG and CIS.
- Lighthouse / PageSpeed / CrUX runs.
- WAVE / axe checks.
- MDN HTTP Observatory / header checks.
- repository review/change controls.
- evidence capture and provenance.
- public market-data methodology mapping.
- pre-audit preparation.
- jurisdiction-trigger matrix.
- exchange-readiness evidence inventory.
- competitor benchmarking.

## Feasible with preparation / external engagement
- independent smart-contract security audit.
- formal verification.
- penetration testing.
- bug bounty.
- SOC 2 / ISO certification.
- reserve attestation / accounting assurance.
- institutional due diligence.

## Intrinsically external
- regulatory registration/authorization.
- independent certification.
- exchange listing decisions.
- editorial publication decisions.
- journal peer-review decisions.

NOVA can replicate preparation, controls, evidence normalization and many automated checks. It cannot turn internal work into external authority.
