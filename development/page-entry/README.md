# Page Entry and Feature Status

This directory contains the canonical page-entry notice and feature-status standard for AstroCrown.

- [Page Entry and Feature Status Standard](./PAGE-ENTRY-AND-FEATURE-STATUS-STANDARD.md) — approved entry-notice behavior, status labels, risk disclosures, DEVNET evidence rules and change control.
- [Feature Status Registry](./feature-status.json) — current page and per-feature status, notice versions and wallet safety disclosures.
- [Page Entry Notice Script](./page-entry-notice.js) — shared page notice, acknowledgement and status-strip behavior.
- [Page Entry Notice Styles](./page-entry-notice.css) — shared presentation and responsive behavior.

## Important status rule

A page being served in staging is not evidence that its features are operational. Page delivery and every feature's operational status are recorded separately. Unlabelled features are treated as **FOR DEVELOPMENT · READ ONLY**. No feature may be marked DEVNET without its exact network, network ID, test asset and verified official faucet link or address.

Changes to notice wording, risks, page status, supported network or behavior require a notice-version update and regression evidence. Public-test acknowledgements do not authorize account actions, transactions or legal waivers.
