A ASTROCROWN Return to AstroCrown

COMMUNITY FEEDBACK · GRIEVANCES · SUGGESTIONS

Feedback & case access

Submit a suggestion or raise a concern. Each submission receives a reference and a separate private access key so that an existing case can remain accessible even when an AstroCrown account is restricted, closed or unavailable.

Keep your case receipt. Your reference code and private access key are separate. The access key is displayed only when issued; save the downloadable receipt somewhere secure. The reference code alone does not reveal your case.

01 · NEW SUBMISSION

Send feedback or raise a grievance

Account not required

You may submit while signed in or without an account. If an active local account session is present, the case is also linked to that account for convenience. The independent case credentials remain valid separately.

Do not include passwords, private keys, seed phrases, full payment credentials or unrelated sensitive information. File attachments are not supported by this development prototype.

02 · INDEPENDENT ACCESS

Open an existing case

No account sign-in

Enter the case reference and private access key from your receipt. This independent route continues to work if your AstroCrown account has been suspended, terminated or closed.

03 · LOST ACCESS

Recover case access

Manual review

You can request recovery if you lose the private case key, the case reference, or both. You do not need an active AstroCrown account. A reference or title/date description helps us locate the case. A reviewer must independently verify your identity and match the request before a replacement key can be issued. A request does not automatically restore access.

Only provide a contact detail needed for verification. The contact information entered here is not considered verified merely because it was submitted. This prototype has no email or SMS delivery provider; review and any replacement-key delivery are manual.

04 · SIGNED-IN VIEW

Cases linked to this account

This is a convenience view. It does not replace the independent case reference and access key.

RESTRICTED WORKSPACE

Administrator case review

Server-authorized session

Visible only after the backend confirms an assigned administrator role and a valid wallet step-up session. Keep internal notes separate from public replies. A grievance concerning an administrator requires an independent-review attestation before any action.

Case-access recovery queue

Before approving a replacement key, independently verify identity outside this case portal. Where the original case reference was lost, match the request to the exact case before approval. Do not send a replacement key through an unverified channel.

How this prototype works: Receipt generation, deterministic category/priority routing, timestamps and case histories run locally in the prototype backend. No AI provider receives submission contents. Substantive findings and decisions require authorized review; this system does not automatically decide whether a grievance is valid.

This is a development prototype using local SQLite storage. No email, SMS or push notifications are sent. Do not enter real personal information or use it for real disputes. See the current Terms of Use draft and Privacy Policy draft.
