ASTROCROWN · DEVELOPMENT PREVIEW

Privacy Policy

DRAFT ONLY — NOT APPROVED FOR PRODUCTION OR REAL USERS

Status: Development draft for the Account dialog only. It does not replace a reviewed production privacy notice and should not be relied on as legal advice or a complete statement of a deployed service's practices.

1. Browser-preview mode

The hosted HTML preview is a disposable interaction demonstration. Account form values and demo account state are processed in page memory only by the prototype; this code does not send account API requests or write account data to browser storage. Reloading or opening a new tab discards the demo account. The preview is served through a third-party HTML-preview service, so never enter real personal information or credentials.

2. Local prototype mode

In the optional localhost test, email address, password hash, creation timestamp, referral ID, Terms acceptance and newsletter opt-in state are stored in a local SQLite database on the test computer. Passwords are not stored in plaintext. This prototype does not send verification messages, password-reset emails, or crypto-news newsletters. The newsletter checkbox records only a local test preference; it does not subscribe the address to a mailing list.

3. Data minimization and purpose

Email is used as the account identifier in this prototype. A Referral ID is an optional unverified test value; it does not trigger rewards or tracking. The crypto-news email preference is separate, optional, and unchecked by default. The development test is not an authorization to contact real people.

4. Retention, deletion and access

Hosted-preview data disappears with the page session. Local test records persist in the configured SQLite database until the test operator deletes that database. This draft does not define production retention periods, access requests, export, deletion, incident notifications, lawful bases, cross-border transfers, or data-subject rights.

5. Third parties and production delivery

No external identity, mailing-list, or email delivery provider is configured by this prototype. Any future service must be evaluated for necessity, cost, data access, retention, security, jurisdiction, privacy, and the project's $0/no-card constraint before activation.

6. Review required

Before collecting real user data, AstroCrown must approve its production hosting and data flows, verify email addresses, implement secure password-reset delivery, define marketing consent and unsubscribe handling, assess legal obligations, and publish an accurate, reviewed privacy notice. No production compliance claim is made.
