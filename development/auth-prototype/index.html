ASTROCROWN · LOCAL DEVELOPMENT ONLY

Optional wallet capability test

A local test of off-chain wallet-message verification for a feature that may genuinely need wallet control. This is not the live AstroCrown site and is not AstroCrown's ordinary account login.

Before you continue

  • Use only a wallet/account created for testing.
  • No funds, tokens, blockchain transactions or gas are required.
  • Never enter or share your seed phrase or private key.
  • Review the complete message before signing. It is a login proof, not a transaction.
  • This server is local-only. Do not expose it to a network or use it for real accounts.
