# Development

This directory contains development-only material that is not part of the regular AstroCrown Web site.

Production/public website files remain at the repository root. Development experiments, prototypes, requirements, audit records, discoveries, and other temporary or development-specific material belong here when they are needed.

Current development structure includes:

- `HOMEPAGE-REQUIREMENTS.md` — homepage specification, candidate states, discoveries, decisions, and explicit undefined items.
- `DEVELOPMENT-AND-AUDIT-CONVENTION.md` — development and verification convention.
- `SECURITY-BASELINE.md` — security baseline.
- `audit/` — audit and verification artifacts.
- `discoveries/` — cross-cutting discoveries and methodology assets, including human-AI prompt/workflow improvements.
- `index.html` — development implementation baseline.

Create additional subdirectories only when an actual artifact or coherent set of artifacts requires them.

The `discoveries/` directory is intentionally preserved as a knowledge asset. It must not become a dumping ground or a substitute for approved requirements; use its status and provenance rules to distinguish discovery from decision and implementation.
