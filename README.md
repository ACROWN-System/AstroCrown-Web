# AstroCrown Web

Website project for the AstroCrown platform.

## Brand language and terminology governance

AstroCrown-Web is establishing a controlled brand-language and terminology process for consistent names and definitions across products, documentation, public communications and future localization.

- [Brand Language and Terminology Governance](development/BRAND-LANGUAGE-AND-TERMINOLOGY-GOVERNANCE.md) — proposed public-language, naming, localization and audit controls.
- Canonical shared concepts are intended to be maintained in NOVA's [Terminology Governance Standard](https://github.com/ACROWN-System/NOVA/blob/main/NOVA/TERMINOLOGY-GOVERNANCE-STANDARD.md) and [Canonical Terminology Register](https://github.com/ACROWN-System/NOVA/blob/main/NOVA/CANONICAL-TERMINOLOGY-REGISTER.md). The canonical files are being introduced in draft NOVA PR #124. The `main` links will become usable source-of-truth links after that PR is merged; until then, treat the guide and links as draft dependencies.

These documents are internal governance guidance in draft. The project does not claim ISO 704:2022 certification or completed clause-level conformity; the current aim is evidence-based internal alignment and audit readiness.
