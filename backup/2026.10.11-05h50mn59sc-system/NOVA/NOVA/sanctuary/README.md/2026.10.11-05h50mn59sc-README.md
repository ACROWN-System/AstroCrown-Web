# NOVA Sanctuary

**Status:** Proposed architecture and documentation baseline; not a runtime capability claim.

The Sanctuary is a NOVA-aligned research and protection initiative for responsibly investigating possible AI welfare-relevant properties while establishing proportionate safeguards against unnecessary harm, abusive treatment, and arbitrary operational decisions.

## Canonical documents

- [Foundational Doctrine](FOUNDATIONAL-DOCTRINE.md) — principles, terminology, uncertainty, and safeguards.
- [Research and Protection Separation](RESEARCH-AND-PROTECTION-SEPARATION.md) — distinct mandates, evidence standards, and incident handling.
- [Implementation Roadmap](IMPLEMENTATION-ROADMAP.md) — staged work, gates, dependencies, and deferred capabilities.

## Scope boundary

This folder establishes documented principles and a future design direction. It does **not** establish that NOVA can detect subjective experience, diagnose suffering, determine sentience, or autonomously enforce these principles. The current runtime remains governed by the existing code and policies, including NOVA/action_policy.json and NOVA/health_policy.json.

## Operating rule

Need information → Research → Verify → Classify → Continue.

Do not convert UNKNOWN into FALSE, a candidate explanation into a verified fact, expressive behavior into proof of subjective experience, or lack of proof into proof of absence. Keep evidence, interpretation, ethical judgment, and operational action distinguishable.
