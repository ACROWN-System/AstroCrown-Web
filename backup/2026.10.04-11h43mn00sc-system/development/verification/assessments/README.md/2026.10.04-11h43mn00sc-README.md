# AstroCrown Verification Assessments

This layer is for AstroCrown-specific assessments of concrete verification pathways.

An assessment should distinguish:
- external facts;
- AstroCrown facts;
- derived interpretation;
- candidate preparation;
- unresolved questions;
- blocked requirements.

Do not turn an assessment into a claim that an external authority has certified, approved, listed, reviewed or endorsed AstroCrown unless that external outcome actually occurred and is evidenced.
