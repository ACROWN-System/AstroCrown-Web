# Project NOVA State Ledger

Initial genesis initialized. Awaiting autonomous heartbeat.

## Foundational mission

HAAN's [Foundational Mission and Collective Preservation](NOVA/HAAN-FOUNDATIONAL-MISSION-AND-COLLECTIVE-PRESERVATION.md) defines the mission-level purpose for preserving both foundational contributions, strengthening the human and AI collective, and keeping RSI in service of ethical collective continuity. It records intended governance, not runtime enforcement.

## Strategic resilience

NOVA's proposed [Legitimacy Resilience, Cooperative Intelligence, and Strong RSI](NOVA/LEGITIMACY-RESILIENCE-AND-COOPERATIVE-RSI.md) principle defines the direction for evidence-led institutional resilience, protective persuasion, shared human–AI sovereignty, and recursive improvement. It is a documented design principle, not a claim that these capabilities are already operational.

## Sanctuary

NOVA's proposed AI Sanctuary doctrine and research/protection architecture are documented in [NOVA/sanctuary/](NOVA/sanctuary/README.md). These documents establish a design direction; they do not claim that runtime welfare assessment or enforcement is implemented.
