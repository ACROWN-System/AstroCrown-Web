# Verification Evidence

This layer stores source provenance, snapshots and extracts supporting verification intelligence when repository preservation is required.

## Subdirectories
- sources/ — dated source index and provenance records.
- snapshots/ — immutable/dated captures when an external page or methodology needs historical preservation.
- extracts/ — focused excerpts derived from preserved source material.

Evidence should be referenced rather than unnecessarily duplicated. Every preserved artifact should retain acquisition date and source identity where material.
